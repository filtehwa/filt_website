# 템프인 복제 테스트 파일

아임웹 템프인 상세페이지 모바일 코드 위젯을 분리해 시험하기 위한 초안입니다.

- `tempin-copy-content.html`: 프로젝트 고유 콘텐츠와 위젯 마크업
- `tempin-copy.css`: 원본 모바일 코드 위젯의 스타일
- `tempin-copy.js`: 메뉴, 사진 슬라이더, 면적 단위 전환, 도면 슬라이더
- `tempin-copy-widget.html`: 아임웹 복제 페이지 코드 위젯 로더

GitHub 연결 권한이 읽기 전용이라 이 파일들은 저장소에 아직 올라가지 않았습니다. 업로드하면 위젯 파일의 `tempin-clone-test` 브랜치 주소가 실제 저장 경로와 일치하는지 확인해야 합니다.

원본 백업 `tempin-mobile.html`은 수정하지 않습니다. 이 초안은 코드를 분리한 것이며, 복제 페이지에서 동작 확인 후 공통 코드를 더 다듬는 과정이 필요합니다.
